# 用户策略部署

目标仅为 chatdev 与 chat.cotti.ai 共享的 lobehub\_history。旧 chat.cotticoffee.com 不在本批范围。

旧应用不读取新策略表。发布前备份旧授权表，事务创建 0164 中的策略表并运行 restore-agent-users.sql，然后逐个替换应用容器。自动迁移随后执行同一幂等建表 SQL 并记录 journal；预建表是为了让新应用第一笔请求就具备完整名单。不要重启 PG 或 QStash。

回填只插入缺失用户，重复执行不会覆盖管理员后续修改。旧启用规则采用原邮箱前缀语义，禁用规则本身不授权，但独立启用前缀仍可命中。初始化是一次性的；新用户默认普通模型、关闭 Agent、继承平台话题限额。

回滚应用镜像即可恢复旧应用行为；保留新表和旧名单备份，不删除历史用户、话题或任务。真实 PG 回滚演练：110 行，24 开启、86 关闭，建表约 2ms、外键约 7ms、回填约 6ms。
