平台管理顶部仅一处 16px 标题，去除重复说明，底部留白为 24px。人员管理采用用户管理 / 管理员设置 / 准入设置，选中页签高对比显示，用户管理卡片不再重复标题和说明。用户管理单行列出所有现有账号，支持搜索分页；VIP / Agent 直接切换开关，金额在单元格内编辑，回车或失焦保存、Esc 取消。姓名悬停或三点按钮查看邮箱、手机号；留空继承平台默认 10 元。旧 Agent 模式选择不恢复。按用户确认的旧名单初始化：110 个现有账号中 24 个开启、86 个关闭；新用户默认关闭。后续按用户 ID 管理，不再自动匹配邮箱前缀。

模型管理提供 VIP 分类，当前模型初始均为普通；VIP 与 Agent、管理员权限独立。Agent 权限在服务端执行步骤按实际 Chat / Agent 模式校验，保持普通 Chat 可用；VIP 在 ModelRuntime 请求前校验。撤销权限不能中止已经发送的上游请求，之后的 Agent 步骤停止。发送前按历史消费加本次完整输入输出估价检查，余额不足提前冻结；输出未设置上限时估算 8192 Token，不假定缓存命中。缺失价表时阻止受保护调用。调整金额不自动解除已冻结话题；此为预检查，并非并发原子预占，估算偏差与并发调用仍可能超出限额。

全览默认列出未冻结话题并按累计模型费用倒序，用户名后固定显示费用；管理侧栏提供实际模型用量、费用完整性、冻结原因、本话题额度和解冻。话题额度优先于用户及平台默认，仅本话题有效；上下文冻结需单独确认。文件 / 产物与助理元信息复用原生只读渲染，原有超长话题 5000 条展示边界保留。
