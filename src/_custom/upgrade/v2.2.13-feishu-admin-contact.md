# 首页飞书联系管理员入口

## 目标

在登录后的桌面首页，将右上角灵枢形象作为 “联系管理员” 的轻量入口。用户点击后通过飞书 AppLink 唤起与指定管理员的单聊，不在 LobeHub 内读取、代理或保存沟通内容。

## 管理员目标

- 飞书用户：韩计成（`jicheng.han@abite.com`）
- OpenID：`ou_2f3bf7b5efa5fd9b70d5d5993b3a2e82`
- AppLink：`https://applink.feishu.cn/client/chat/open?openId=ou_2f3bf7b5efa5fd9b70d5d5993b3a2e82`

OpenID 由当前飞书自建应用通过官方 “邮箱获取用户 ID” 接口解析，账号状态为已激活、未冻结、未离职。`jicheng.han@cotticoffee.com` 是独立邮箱注册账号，没有对应飞书 OpenID。

## 交互

1. 仅登录用户可见，沿用首页原有形象展示条件。
2. 配置有效时，鼠标悬停显示 “通过飞书联系管理员”，点击在新窗口打开飞书 AppLink，当前首页不丢失。
3. 支持键盘聚焦和回车打开；焦点使用主题色轮廓。
4. 未配置或配置不合法时，形象继续作为装饰，不产生空链接或错误入口。
5. 首页在容器宽度不超过 1100px 时原本就隐藏形象，因此本期不增加移动端入口。

## 配置与安全边界

```dotenv
NEXT_PUBLIC_COTTI_FEISHU_SUPPORT_URL=https://applink.feishu.cn/client/chat/open?openId=ou_2f3bf7b5efa5fd9b70d5d5993b3a2e82
```

客户端只接受以下链接：

- HTTPS；
- 主机名严格为 `applink.feishu.cn`，不允许自定义端口；
- 路径严格为 `/client/chat/open`；
- `openId` 必须是 `ou_` 开头的飞书 OpenID。

这是公开的客户端跳转地址，不包含飞书应用密钥、用户令牌或聊天内容。该能力与飞书 SSO、飞书资料 Connector 相互独立，不修改现有登录身份映射和 OAuth 权限。

## 代码触点

- `src/features/Home/HomePortrait.tsx`：可访问的形象链接与悬停提示；

- `packages/locales/src/default/home.ts`、`locales/en-US/home.json`、`locales/zh-CN/home.json`：中英文文案；
- `.env.example`：部署配置示例；
- `src/_custom/deploy/prod-01-check-runtime.sh`：生产发布前校验；
- `src/_custom/deploy/prod-04-verify-app-update.sh`：生产验收运行时配置校验。

## 验收

1. 无配置时形象无点击和键盘入口。
2. 正确配置时悬停文案正确，点击保留当前页面并唤起飞书。
3. 飞书进入与 “韩计成” 的单聊，而不是机器人、群聊或其他同名用户。
4. 非飞书域名、HTTP、错误路径或非 `ou_` 身份均不会生成链接。
5. `prefers-reduced-motion` 用户不播放悬停位移动画。
