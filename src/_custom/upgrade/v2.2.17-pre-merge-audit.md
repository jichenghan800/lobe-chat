## 飞书三类能力

| 能力       | 原理与用途                                           | 本轮处理                                                   |
| ---------- | ---------------------------------------------------- | ---------------------------------------------------------- |
| 飞书登录   | 普通 / 蓝版 OAuth 登录网页                           | 最小版已保留，不关联或合并账号                             |
| 飞书资料   | 个人授权的资料搜索 / 读取 / 创建、表格与聊天记录查询 | 补回连接器及权限检查                                       |

机器人组件不是本轮新增二开。官方 `apps/server/src/services/bot/platforms/feishu/definitions/feishu.ts` 注册平台，`definitions/schema.ts` 提供 App ID、App Secret、长连接 / Webhook、人员与群聊策略；`gateway.ts` 接收消息事件。官方新文档读取位于机器人消息服务，与个人资料连接器权限主体不同。当前是否配置上线没有在本轮核验。
