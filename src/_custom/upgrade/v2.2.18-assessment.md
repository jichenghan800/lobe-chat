# v2.2.18 升级初评（2026-09-24）

结论：建议进入隔离升级验证，暂不直接替换任何现有服务。本轮仅源码对比、隔离试合并与运行配置是否存在的只读检查；未升级数据库、未执行新版产品测试、未部署。

## 基线与证据

- 当前分支评估基线 `43cc5802c0`，当前运行源码 `147592dd99`，v2.2.17 图片适屏镜像。
- 官方 v2.2.18 `14dfc07b14eee1984e52c195df9319636d6b167b`；与当前分支共同基线 `787e3d20aa8194a4d4aafe40f0e48bd21d654045`。本地 v2.2.17 标签对象为 cd2428333a，避免把标签对象和共同提交混淆。
- 官方版本区间 177 个非合并提交、1999 个变更文件；其中迁移快照占大量新增行，不能把行数当作业务改动量。
- 当前相对共同基线有 782 个变更文件，双方重叠 96 个；隔离试合并得到 34 个冲突文件。文件数不是二开功能数量，无文本冲突也不等于行为兼容。
- 原目录和运行容器不变；试合并没有执行 hooks、安装依赖、连接数据库或运行应用。

## 对本平台的收益

1. Agent 操作令牌续期、连续服务端步骤、共享消息读取与步骤内不变信息复用，有助于长任务稳定性与服务端效率；不能据此承诺模型 Token 或费用下降。
2. 沙箱代码执行 / 导出失败现在明确 success=false 并保留错误；避免把失败当成功，但可能改变 Agent 继续执行策略，需要验收超时、授权拒绝与自建沙箱。
3. 工具结果轻量展示由 gatewayMux 实验开关控制，按需恢复完整输出。主要减少传输 / 展示负担，不等于自动压缩模型上下文。
4. 文稿选区评论、资源内联详情、停止回复时保留输入草稿等体验改进，可优先原生验收。
5. pg\_like 可选择无扩展查询后端，但历史迁移仍依赖 pg\_search，不能据此直接切换普通云 PostgreSQL。
6. Environment / Instance 本轮主要是 schema 基础，不能替代已落地 OnlyBoxes、容量管理、话题沙箱固定策略。

## 升级阻碍与发布条件

### 数据库：必须先解决

官方新增 0162\_fts\_capture\_version、0163\_environments、0164\_document\_comment\_selection\_anchor、0165\_expertise\_rejection\_provenance、0166\_device\_architecture；我们已有 0162–0165 的准入成本、平台管理、沙箱容量与用户组迁移。SQL 名称虽不同，journal 索引和 snapshot 路径直接冲突，时间戳交错还可能导致按最新时间戳判断时跳过官方迁移。

禁止直接覆盖 journal /snapshot 或删除已执行二开 SQL；先按两库迁移记录、SQL 哈希、现有 schema 分别核对，制定向前兼容方案，并在副本验证重复执行和应用回退。未验证前为发布阻断项。

### 执行链路：不能照抄新 Compose

官方 Compose 默认开启 Gateway，增加 gateway 服务及部署专用签名 / 公钥、服务令牌、浏览器可达地址和内部地址。当前开发两入口及生产应用均未配置 ENABLE\_AGENT\_GATEWAY、AGENT\_GATEWAY\_URL / INTERNAL\_URL / SERVICE\_TOKEN，只有 JWKS\_KEY 存在；未读取或输出密钥值。

这不代表新版不带 Gateway 就不能启动；官方说明缺失配置会警告并回退浏览器执行。必须明确本轮沿用原路径还是单独启用 Gateway，验证模型渠道 / VIP / 冻结额度 / 成本记录在实际路径生效。不要把应用升级与运行架构切换、Docker 升级同时捆绑。

## 建议仍按三步推进

1. 固定当前源码 / 镜像及回退点，备份数据库和附件引用，建立隔离分支与两环境各自的数据库副本。新版官方加登录、存储等必要适配，先解决迁移并做最小验收。
2. 一次性合并剩余必要二开：以源码覆盖表决定保留 / 替换 / 移除，先过模型渠道、权限、计费冻结、上传下载、两类沙箱和任务回归，再验收 UI。
3. 验收通过后安排服务切换。开发两个域名按现有要求同步；生产另设窗口。切换前归档当前静态资源、等待运行任务、停机一致性备份，回退只切应用并保留新数据。

关键验收：历史与新话题；Chat/Agent/Job；普通组与压测组；金额预留、累计费用和冻结；大 Excel/CSV；OnlyBoxes 文件读写 / 相对导出及云端授权失败；委派 Skill 工具清单；全览 / 分享；刷新与旧页面动态资源；图片适屏。尚无新版通过结论。
