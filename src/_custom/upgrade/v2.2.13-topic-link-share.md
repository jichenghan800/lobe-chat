# v2.2.13 COTTI 话题链接分享兼容说明

## 业务目标

用户完成一段分析后，可以生成网页链接并发给他人直接阅读。获得链接的人无需登录，分享者可以随时将链接切回私密状态。

## 官方能力与自托管缺口

LobeHub v2.2.13 已包含完整的话题链接分享能力：

- `topic_shares` 数据表保存短分享 ID、可见性和浏览量；
- `share.getSharedTopic` 与消息查询接口支持匿名读取；
- `/share/t/:shareId` 提供只读会话页面；
- `SharePopover` 提供私密 / 链接可见性切换、风险确认和复制链接。

但会话页的分享按钮仅在官方 `ENABLE_BUSINESS_FEATURES` 为真时展示 `SharePopover`。开源自托管版本将该总开关固定为 `false`，因此用户只能看到图片、文本和 PDF 导出入口。

## COTTI 最小兼容

新增独立静态开关 `COTTI_TOPIC_LINK_SHARE_ENABLED`，仅在 Agent 会话和群聊会话的分享按钮中启用官方 `SharePopover`。

明确不做以下变更：

- 不修改官方 `ENABLE_BUSINESS_FEATURES`；
- 不启用订阅、计费或其他云端商业功能；
- 不修改分享数据库结构、服务端权限判断或公开分享路由；
- 不复制或重写官方分享页面。

## 分享语义与安全边界

- `private`：只有分享创建者可以访问；
- `link`：任何获得链接的人都可以匿名访问；
- 分享内容是话题的实时视图，不是创建分享时的静态快照；
- 后续追加到同一话题的消息也会出现在分享页；
- 分享页可能展示上传文件、图片和工具调用结果，切换到链接可见性前继续使用官方风险确认；
- 分享页跳过 Work 摘要，避免匿名访问者读取分享后发生变化的任务状态。

## 升级触点

| 文件                                                                         | COTTI 变更                     |
| ---------------------------------------------------------------------------- | ------------------------------ |
| `src/_custom/registry/topicLinkShare.ts`                                     | COTTI 独立话题链接分享开关     |
| `src/routes/(main)/agent/features/Conversation/Header/ShareButton/index.tsx` | Agent 会话启用官方链接分享弹层 |
| `src/routes/(main)/group/features/Conversation/Header/ShareButton/index.tsx` | 群聊会话启用官方链接分享弹层   |

后续升级时，如果官方将话题链接分享从 `ENABLE_BUSINESS_FEATURES` 中独立出来，应优先删除 COTTI 开关并直接采用官方配置。
